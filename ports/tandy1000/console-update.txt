Tandy ELKS: graphics modes, mouse choices and return to the shell

This update is for an existing Tandy CompactFlash image. It preserves the
partition layout, configuration and unrelated files.

With ELKS shut down and the CF card in your PC's reader, copy all three files
from the ZIP's bin folder into the CF card's BIN folder:
  NXSTART, NANO-X, NXCGA
Overwrite the old versions. Copy the files as-is; do not decompress them.
Safely eject the card and boot the Tandy again.

Run 'nxcga tandy mouse' or 'nxcga tandy none' for native Tandy 320x200
16 colors. 'nxcga color mouse/none' is standard 4-color CGA, and
'nxcga mono mouse/none' retains the original 640x200 black-and-white mode.
'nxcga mouse' and 'nxcga none' still work, and select 16-color Tandy by default.
The mouse option always uses the single COM1 serial port.

Ctrl+A should close graphics and return to a visible # prompt. Q in
the launcher exits; in Tetris Q closes that app first. The session manager
restores terminal settings, clears the console and waits for child processes.
This package also includes a serial mouse driver that recovers from lost
Microsoft packet boundaries and disables 2x acceleration. The serial mouse
defaults to the 5-byte Mouse Systems protocol (`pc`) after hardware feedback
on fresh images. Existing cards may still set `MOUSE_TYPE=ms` in their old
`/etc/profile`; use `nxcga tandy mouse pc` to override it explicitly.
`nxcga tandy mouse ms` selects Microsoft protocol for comparison. Nano-X
also groups queued movement updates to reduce cursor redraw lag on the V20,
without skipping mouse button transitions. `MOUSE_BATCH=1 nxcga mouse`
disables grouping for comparison; the default is 12. If replacing only
NANO-X/NXSTART/NXCGA without rewriting the CF card, these defaults still apply.
Video color modes, cursor response, and shell return require hardware retest.
